# Grammar Tutor

Grade 8 English grammar practice, aligned to the Common Core Language standards (L.7.1, L.8.1, L.8.2).

- **Chunk Hunt** (`chunk-hunt.html`): a practice page in the "select the chunks" format. Six missions built on long, multi-clause sentences: verbs, complete subjects, prepositional phrases, verbals, active and passive voice, and Color Lab, where the student colors every structure in a sentence. After each answer the whole sentence is shown color-coded; after a miss there is an explanation and two worked examples.
- **Question bank** (`question-bank.js`): all sentences, rules and worked examples, kept apart from the game code. The format is documented at the top of the file.
- **Parent Portal** (`parent-portal.html`): progress by skill, error patterns, and nine metrics for judging whether tutoring is working. It reads an `answers.jsonl` file you choose from your own device. Nothing is uploaded.

Live site: https://eezzz.github.io/grammar-tutor/

This repository holds no student data.
